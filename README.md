# Felipe Modas

Vitrine local de moda feminina com busca, categorias, variações de tamanho e cor e carrinho. O carrinho fica salvo no navegador. O projeto usa HTML, CSS e JavaScript e abre pelo arquivo `index.html`.

O catálogo registra os produtos, as fotos principais, os preços públicos em reais e a disponibilidade mostrada pela Stella Basic em 23/11/2026. Das 281 URLs de produto no mapa público, 235 tinham uma página de produto e 46 retornavam a página de item indisponível. As fotos são referenciadas pelo CDN da loja e precisam de conexão com a internet.

O botão Comprar fecha o carrinho e volta ao topo da página. Preço e disponibilidade são dados da coleta, sem sincronização em tempo real.
